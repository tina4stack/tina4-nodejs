# Internationalization (i18n)

Tina4 provides JSON-based internationalization with locale fallback, parameter substitution, and nested key support. Zero dependencies.

## Setup

Create JSON translation files in `src/locales/`:

```json
// src/locales/en.json
{
  "greeting": "Hello, {name}!",
  "items.count": "{count} items found",
  "errors.not_found": "The requested resource was not found",
  "buttons.submit": "Submit"
}
```

```json
// src/locales/fr.json
{
  "greeting": "Bonjour, {name} !",
  "items.count": "{count} articles trouves",
  "errors.not_found": "La ressource demandee est introuvable",
  "buttons.submit": "Soumettre"
}
```

## Basic Usage

```typescript
import { I18n } from "@tina4/core";

const i18n = new I18n("src/locales", "en");  // Directory, default locale

// Simple translation
i18n.t("buttons.submit");  // "Submit"

// With parameter substitution
i18n.t("greeting", { name: "Alice" });  // "Hello, Alice!"
i18n.t("items.count", { count: "42" }); // "42 items found"

// Switch locale
i18n.setLocale("fr");
i18n.t("greeting", { name: "Alice" });  // "Bonjour, Alice !"

// Override locale per call
i18n.t("greeting", { name: "Alice" }, "en");  // "Hello, Alice!" (uses English)
```

## Locale Fallback

If a key is not found in the current locale, Tina4 falls back to the default locale. If still not found, the key itself is returned.

```typescript
const i18n = new I18n("src/locales", "en");
i18n.setLocale("fr");

// Key exists in French
i18n.t("greeting", { name: "Bob" });  // "Bonjour, Bob !"

// Key missing in French, falls back to English
i18n.t("some.english.only.key");  // Value from en.json

// Key missing in both, returns the key itself
i18n.t("totally.unknown.key");  // "totally.unknown.key"
```

## In a Route Handler

```typescript
import type { Tina4Request, Tina4Response } from "@tina4/core";
import { I18n } from "@tina4/core";

const i18n = new I18n();

export default async function (req: Tina4Request, res: Tina4Response): Promise<void> {
  // Detect locale from Accept-Language header or query param
  const locale = req.query.lang ?? req.headers["accept-language"]?.split(",")[0]?.split("-")[0] ?? "en";
  i18n.setLocale(locale);

  res.json({
    message: i18n.t("greeting", { name: "World" }),
    locale: i18n.getLocale(),
  });
}
```

## Configuration

```typescript
const i18n = new I18n(
  "src/locales",  // Directory containing .json files (default: "src/locales")
  "en",           // Default locale (default: "en")
);
```

### Environment Variables

```bash
# .env
TINA4_LOCALE_DIR=src/locales
TINA4_LOCALE=en
```

## API

| Method | Description |
|--------|-------------|
| `t(key, params?, locale?)` | Translate a key with optional parameter substitution |
| `setLocale(locale)` | Set the current locale |
| `getLocale()` | Get the current locale |

## Notes

- Translation files are loaded lazily on first access per locale.
- Parameter placeholders use `{name}` syntax.
- Flat key structure is used (dot-separated keys like `"errors.not_found"`).
